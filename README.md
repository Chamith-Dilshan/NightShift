# NightShift: Advanced Media Tool

NightShift is a powerful, locally-running desktop application designed to process video, audio, and images effortlessly. Built with a modern technology stack, it provides a high-performance visual interface to construct complex FFmpeg and WebP commands without ever touching a command line directly.

## 🏗 Architecture & Stack

NightShift employs a cutting-edge triple-stack architecture for maximum performance and native system access:

1. **Frontend (Next.js + React + Redux + TanStack)**
   - **Framework:** Next.js (App Router, static export).
   - **State Management:** Redux Toolkit is the backbone of the UI. It maintains the massive, reactive configuration state (video codecs, filters, audio bitrates) and auto-corrects incompatible settings (e.g., automatically switching to VP9 when WebM is selected).
   - **UI/UX:** Tailwind CSS + shadcn/ui. Features a dark-mode "cyber/neon" aesthetic.
   - **Data Fetching/Forms:** TanStack React Query & React Form handle async operations and validations effortlessly.

2. **Native Container & Backend (Tauri V2 - Rust)**
   - **Core App:** Packaged as a lightweight desktop binary using Tauri V2.
   - **System Integration:** Rust handles profound OS-level events. `src-tauri/src/lib.rs` listens for native OS drag-and-drop events and forwards the actual file paths securely to the frontend (bypassing browser blob URI limitations).
   - **Capabilities:** Strict permissions configured in `default.json` safely allow dialog pickers, file system access, and native clipboard management.

3. **Sidecar Engine (FastAPI - Python)**
   - **Execution Layer:** A lightweight FastAPI server designed to run alongside Tauri.
   - **Process Management:** Evaluates and safely executes the complex FFmpeg commands generated by the Redux store using Python's `subprocess` module.
   - **Streaming Output (Upcoming):** Will stream live terminal output back to the Next.js UI via Server-Sent Events (SSE).

## ⚙️ How It Works (The Redux Command Builder Flow)

1. **User Interaction:** The user interacts with 7 distinct control panels (Input, Output, Video, Audio, Filters, Transform, Watermark).
2. **Reactive Validation:** As settings change, `videoSlice.ts` reactively maps settings. If the user selects "webm", Redux instantly forces compatible video/audio codecs.
3. **Command Generation:** `commandBuilder.ts` takes the entire validated Redux state and dynamically constructs a perfect FFmpeg string array. It calculates complex filter graphs (e.g., injecting `palettegen` and `paletteuse` filters automatically for high-quality GIFs or appending `overlay` filters for watermarks).
4. **Execution:** The command is sent to the FastAPI sidecar (`/run`) which executes the binary on the host machine.

## 🚀 Getting Started

### Prerequisites
- Node.js & npm
- Rust & Cargo (`rustc`, Cargo)
- Python 3.13+ & `uv` or `pip`

### 1. Start the FastAPI Sidecar
The sidecar must be running to process media commands.
```bash
cd fastapi
python -m venv .venv
source .venv/bin/activate  # On Windows: .venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

### 2. Start the Tauri App (Frontend + Rust)
In a separate terminal, run the main UI.
```bash
npm install
npm run tauri dev
```

## 📁 Directory Structure

- `src/app/` - Next.js page definitions and layouts.
- `src/components/videoTool/` - The visual parameter panels (Video, Audio, Filters).
- `src/store/` - Redux Toolkit slices (`videoSlice.ts`) and the critical `commandBuilder.ts`.
- `src-tauri/` - Rust core. `lib.rs` handles plugins and window events.
- `fastapi/` - Python execution layer. `app/services/media.py` manages subprocess executions.
